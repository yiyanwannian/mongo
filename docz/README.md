## 快速导航

### 🚀 快速开始
如果您是第一次接触MongoDB源码：
1. 先阅读 `mongodb_project_overview.md` 了解整体架构
2. 查看 `mongodb_architecture.puml` 理解系统设计
3. 参考 `mongodb_development_guide.md` 搭建开发环境

### 🔍 深入理解
如果您需要深入了解内部机制：
1. 研究 `mongodb_module_architecture.md` 了解模块结构
2. 分析 `mongodb_module_interaction.puml` 理解模块交互
3. 查看 `mongodb_query_processing_architecture.puml` 了解查询处理
4. 研究 `mongodb_components_interaction.puml` 了解组件交互
5. 分析 `mongodb_storage_engine.puml` 理解存储层设计
6. 结合源码进行实际调试和分析

### 🛠️ 开发贡献
如果您计划为MongoDB贡献代码：
1. 详细阅读 `mongodb_development_guide.md`
2. 了解代码规范和测试要求
3. 熟悉构建系统和调试工具
4. 参考 `mongodb_module_architecture.md` 理解代码结构
